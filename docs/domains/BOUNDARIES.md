# Domain Boundaries

Операционная изоляция доменов Stylo.

| Домен | Entry points | Владеет | Не владеет |
|---|---|---|---|
| corpus/data | `src/stylo/corpus/`, манифесты корпуса, скрипты добора и валидации | provenance, нормализация, группировка, пригодность корпуса | заявления о моделях и оценках |
| feature-extraction | `src/stylo/features/`, `configs/`, resources | контракты признаков и построение векторов | вердикты атрибуции |
| evaluation/paired-audit | `src/stylo/eval/`, `src/stylo/domain/`, `scripts/evaluation/` | estimand'ы, контракты сплитов и контролей, скоринг, идентичности прогонов | формулировки публикаций |
| reporting/publication | `src/stylo/report/`, `docs/`, генерируемые публичные данные | артефакты отчётов, ограниченные заявления, ссылки на провенанс | сырые приватные корпуса |
| site | `site/`, `scripts/gen-site-data.mjs`, проверки провенанса | сборка интерактивной статьи и публичная подача | научные реестры-источники |
| research-governance | `research/governance/`, протоколы, реестры evidence | текущий статус, требования, топология, научные гейты | владение реализацией каждого производителя |

Имя каталога не доказывает ownership: источник истины — код, исполняемая конфигурация и принятая
governance-запись. Пока конкретный domain doc не создан, владелец — repository owner.

## Разрешённые зависимости

```text
corpus/data -> feature-extraction -> evaluation/paired-audit
     |                                  |
     v                                  v
research-governance <---------- reporting/publication -> site
```

Стрелка означает разрешённый явный контракт, а не право переносить семантику.

## Типовые утечки

- перенос метрики в другой домен по совпадению имени — одинаковое имя не доказывает одинаковый
  estimand (пример: macro-F1 на 43-классовом срезе и на публикуемом 22-классовом);
- соединение артефактов с разным grain без проверки кардинальности;
- копирование доменных фильтров как универсальных;
- сокрытие научной семантики в общем слое;
- расширение селекторов с неявной утечкой held-out данных.

# UI-kit и статья: исправления по скриншотам и комплексный review

Владелец указал на лишние линии у раскрывающихся разделов, прежнюю dashboard-композицию
контрольных панелей и источники без действующих ссылок. Дополнительно запросил комплексный
review UI-кита и верстки статьи. Baseline authorship — `47c9027`, дерево было чистым.

## Исправления статьи

- У details и соседних смысловых разделов убраны повторяющиеся линии. Limits изложен четырьмя
  таблицами и связными пояснениями, без Badge/полос/статусного «гейта». Сохранены численные
  значения, пороги и условия сравнения; имеющееся в источнике p для символьных триграмм показано.
- Sources теперь содержит работающие загрузки агрегатов каждой главы и контрольных панелей.
  Пять JSON в `site/public/evidence/` генерируются из уже используемых на сайте наборов; сырые
  отчёты, литературные и личные тексты не копируются. В файлах есть агрегаты и хеши источников.
  Проверка provenance сверяет JSON с отображаемыми данными, включая попытку подмены output digest.
- Убраны неработающие как читательские ссылки пути docs/*.json и зависимость загрузок от GitHub.
  ФЭБ frameset заменён содержательным описанием собрания; добавлена карточка научного издания
  ИМЛИ. PDF Великановой/Орехова открывается с нужной страницы. Общий каталог az.lib.ru не выдаётся
  за источник конкретного корпуса. Название тома ГАРФ уточнено по карточке.
- Дополнительный browser review выявил схлопывание полос графиков на tablet/mobile, скрытый
  target `#framework/limits`, потерю route после skip-link, пропущенный h2 в главах и неподкреплённые
  источниками badges правдоподобия кандидатов. Эти четыре группы P2 исправлены. Поправлены
  склеенные слова, падежи и первое лицо в пояснениях.

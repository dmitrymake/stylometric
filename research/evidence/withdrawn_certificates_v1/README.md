# Withdrawn certificate method — historical evidence

The files in this directory preserve the exact pre-withdrawal implementation, its generated output,
and the contemporary falsification record. They are inert evidence: the Python source is stored with
the `.txt` suffix and is not importable as package code.

The method treated chunk repetitions as independent tensor-product observations and then used the
minimum per-channel floor as though it were a valid joint lower bound. Project evidence records
achieved errors below 546 of 903 claimed floors. Its inferential API is therefore withdrawn with
status `WITHDRAWN_INVALID_UNIT`.

Do not execute or cite the historical verdicts as valid certificates. Descriptive distance helpers
in the live package remain separate from the withdrawn lower-bound and verdict APIs.
